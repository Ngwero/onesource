# App Store listing — location use (draft)

Use this short plain-language note in the App Store privacy / description text.
It is **not** a full privacy policy PDF.

## Suggested App Store wording

**Location**

One Source does **not** use GPS or continuous location tracking.

When you open the app we look up the **country of your IP address** (via a country
lookup service) so we can suggest a delivery country, currency, and language.
We only keep the country code — not your precise coordinates — and you can change
“Deliver to” at any time in the app.

Precise location is **not** collected for shopping, search, or browsing.

## In-app

The same explanation appears on:

- Privacy / Cookie Notice (`/privacy` and the in-app Privacy screen)
- Deliver-to picker accessibility text (`header.locationUseHint` in all locales)
